# Security

Do not publish credentials, access tokens, customer documents, or private workspace data in this repository or its issues.

Report suspected vulnerabilities through your existing private V7 support channel or [contact V7](https://www.v7labs.com/contact) to arrange private disclosure. Include affected package versions and reproduction steps without secrets or customer data.

This package connects to V7 Go's hosted MCP service over HTTPS. The AI client handles OAuth; permissions are evaluated by the service for the authenticated account and workspace. Use your client's approval controls for consequential actions.

See the [V7 Trust Center](https://trust.v7labs.com/) for service security information.
